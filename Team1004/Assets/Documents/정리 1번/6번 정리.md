# 보스 2 — 곰 최신 Unity 구현 명세

## 1. 핵심 표현

### 곰 본체
**전면에 실제 곰 캐릭터를 배치하지 않는다.**

화면의 배경/강가에는:
- 큰 곰의 그림자
- 곰 실루엣
- 또는 곰이 밖에 있다는 것을 느끼게 하는 그림자

만 존재한다.

### 실제 공격체
실제 Gameplay Layer에는 **곰 팔만 등장**한다.

팔 리소스는 2종이다.

1. `BearArm_Back`
   - 손등이 보이는 팔
   - 순차 연속 공격 전용
2. `BearArm_Side`
   - 손 옆면이 보이는 팔
   - 한 레인 또는 여러 레인 동시 직선 공격 전용

곰의 몸과 팔을 긴 하나의 스프라이트로 연결하지 않는다.

# 2. 보스전 월드

## 시작
게임 진행 2 종료 후 곰 구역에 진입.

- 약 0.5초 동안 월드 지형 스크롤 감속
- 정지
- `BOSS 2 / 곰` 1초
- 그 뒤 실제 30초 타이머 시작

## 30초 동안 고정
고정:
- 강가
- 바위
- 나무
- 곰 그림자
- 큰 배경 지형

계속 움직임:
- 수면 파동
- 물속 흐름선
- 기포
- 작은 반복 물 효과

## 종료
30초가 되면:
1. 새 공격 예약 금지
2. 이미 진행 중인 공격은 끝까지 마침
3. CLEAR 1초
4. 월드 스크롤 약 0.5초에 걸쳐 정상 속도로 복귀
5. 곰 그림자/곰 구역이 왼쪽으로 이동해 사라짐
6. GAME_SECTION_3 시작

# 3. 팔 공격 타입 A — 손등형 연속 공격

ID:
`BEAR_BACKHAND_SEQUENCE_123`

사용 스프라이트:
`BearArm_Back`

## 목적
플레이어가 한 번의 안전 레인만 고르는 것이 아니라
**1 → 2 → 3 순서로 연속 반응**하게 하는 패턴.

## 순서
공격 순서는 고정:

> **1번 → 2번 → 3번**

## 빨간 히트박스/경고 타이밍

`sequentialStepInterval = 0.5초`

권장 정확 이벤트:

- t = 0.00
  - 1번 레인 빨간 경고 표시
- t = 0.50
  - 1번 실제 타격
  - 2번 레인 빨간 경고 표시
- t = 1.00
  - 2번 실제 타격
  - 3번 레인 빨간 경고 표시
- t = 1.50
  - 3번 실제 타격
- 마지막 타격 종료 후 공통 휴식

즉 플레이어가 보는 위험 예고는:

> 1 표시 → 0.5초 → 2 표시 → 0.5초 → 3 표시

형태다.

## 팔 이동
각 단계마다 같은 `BearArm_Back` 프리팹을 재사용한다.

- 오른쪽 화면 바깥/공격 시작점에서 생성
- 해당 레인 Y 위치로 정렬
- 짧게 레인 안으로 진입하며 타격
- 타격 후 즉시 비활성 또는 오른쪽으로 복귀
- 다음 단계에서 같은 프리팹을 재사용 가능

권장:
- 실제 Collider 활성시간: 0.15~0.20초
- 팔 진입/타격 애니메이션: 0.20~0.30초
- 정확한 픽셀 거리는 Inspector 조정값으로 노출

## 중요한 시각 규칙
- 1번 타격 그래픽은 1번만 침범
- 2번은 2번만
- 3번은 3번만
- 안전 레인에 팔 그래픽이 걸쳐 보이지 않게 한다.
- 콜라이더는 보이는 손/팔보다 약간 작게.

# 4. 팔 공격 타입 B — 손 옆면형 직선 공격

사용 스프라이트:
`BearArm_Side`

역할:
**한 레인 또는 여러 레인을 동시에 오른쪽→왼쪽으로 쭉 공격**

## 패턴 후보

### Single
- `SIDE_1` → [1]
- `SIDE_2` → [2]
- `SIDE_3` → [3]

### Double
- `SIDE_12` → [1,2]
- `SIDE_23` → [2,3]

`[1,3]` 없음.

## Single 구현
- `BearArm_Side` 1개 사용
- 타깃 레인 Y만 변경
- 동일한 코드/스프라이트 재사용

## Double 구현
- `BearArm_Side` 동일 프리팹을 2개 동시에 사용
- [1,2]이면 1/2번 Y 위치
- [2,3]이면 2/3번 Y 위치
- 두 팔은 같은 프레임/같은 속도로 동시 이동
- 별도의 Double 전용 그림을 새로 만들 필요 없음

## 타이밍
기존 보스 기본 규칙 사용:

- 빨간 위험 레인 예고: 1.2초
- 실제 우→좌 공격: 0.6초
- 휴식: 0.6초

## 이동
- 팔은 화면 오른쪽 공격 시작점에서 생성
- 해당 레인을 따라 왼쪽으로 쭉 이동
- 플레이어 X 위치를 약간 지나치는 정도까지 이동
- 공격 종료 후 Collider OFF
- 즉시 비활성하거나 오른쪽으로 복귀
- 복귀 중 판정 없음

# 6. 패턴 선택 — 초기 구현값

아직 플레이테스트 조정 가능.

권장 시작 가중치:

- `BEAR_BACKHAND_SEQUENCE_123` : 25%
- SIDE Single 전체 : 45%
  - SIDE_1 : 15%
  - SIDE_2 : 15%
  - SIDE_3 : 15%
- SIDE Double 전체 : 30%
  - SIDE_12 : 15%
  - SIDE_23 : 15%

규칙:
- 직전과 완전히 동일한 Pattern ID 즉시 반복 금지
- 항상 최소 1개의 회피 방법이 존재해야 함

이 가중치는 ScriptableObject/Inspector에서 수정 가능하게 만든다.

# 7. 점프와 곰 공격

현재 게임의 최신 규칙:

> 연어가 물 밖에 있는 동안 아무것에도 맞지 않는다.

따라서:
- 곰 팔은 기본적으로 수중 레인 공격
- 연어가 완전히 물 밖으로 점프했다면 공격 회피 가능

곰 보스에 별도의 공중 공격은 추가하지 않는다.

# 8. 경고/Collider

## 빨간 경고
- 공격 대상 레인을 반투명 빨강으로 표시
- 손등형은 1→2→3 순서로 0.5초 간격
- 손 옆면형은 선택된 한/두 레인을 동시에 1.2초 예고

## 실제 Collider
- 팔 스프라이트와 함께 이동
- SpriteRenderer보다 약 5~10% 안쪽 권장
- 빨간 경고보다 실제 공격판정이 커지면 안 됨

---

# 9. 필요한 그래픽 리소스

필수:
1. `BearShadow`
   - 배경용 곰 그림자/실루엣
2. `BearArm_Back`
   - 손등이 보이는 공격 팔
3. `BearArm_Side`
   - 손 옆면이 보이는 직선 공격 팔

선택:
- 공격 속도선
- 작은 그림자
- 간단한 팔 이동 잔상

필수 아님:
- 물 튀김
- 고급 파티클
- 곰 전신 애니메이션
- 곰 걷기/수영/사망 애니메이션

# 12. 구현 시 금지

- 곰의 전신을 공격마다 직접 움직이기
- 곰 팔을 몸과 화면 끝까지 길게 연결
- [2,3] 공격인데 1번 안전 레인까지 팔 그래픽이 통과
- 공격과 상관없는 큰 물보라
- 안전 레인에 공격 그래픽이 들어옴
- 손등형 1→2→3 순서를 랜덤으로 바꿈
- 0.5초 간격 규칙 무시
