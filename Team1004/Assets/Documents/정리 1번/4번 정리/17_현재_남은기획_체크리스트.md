# 현재 남은 기획 체크리스트

## A. 일반 장애물 세부 동작
- [ ] 돌 정확한 속도
- [ ] 다른 물고기 정확한 속도
- [ ] 통나무 정확한 속도
- [ ] 통나무 길이/점유시간
- [ ] 세 장애물 플레이 차별성

## B. 일반 장애물 생성 패턴
- [ ] 완전 랜덤 vs 패턴 기반
- [ ] 2레인 동시 조합 여부
- [ ] 연속 레인 이동 패턴 여부
- [ ] 회피 불가능 조합 방지
- [ ] 점프 필수 일반 패턴 여부

## C. 일반 구간 수치
시간은 확정:
- 진행 1 = 25초
- 진행 2 = 30초
- 진행 3 = 35초
- 진행 4 = 15초

남은 것:
- [ ] 각 구간 스폰 간격
- [ ] 장애물 이동속도 단계
- [ ] 진행 4 장애물 양

## D. 보스 패턴 순서
- [ ] 직전 패턴 즉시 반복 금지 여부
- [ ] 후반 공격 간격 변화 여부
- [ ] 패턴별 등장 확률

## E. 조작 안내
- [ ] ↑/↓ 안내 방식
- [ ] 점프 안내 방식
- [ ] 별도 튜토리얼 필요 여부

## F. 화면 전환
- [ ] 일반 → 컷신
- [ ] 컷신 → 보스
- [ ] 보스 클리어 표시
- [ ] 보스 → 다음 일반
- [ ] 엔딩 후 메뉴

## G. 충돌 판정
권장:
- 스프라이트보다 실제 히트박스 약 10~15% 작게

남은 것:
- [ ] 연어 히트박스
- [ ] 장애물 히트박스
- [ ] 보스 예고영역과 실제 판정 일치

## H. 상류 단차 점프
- [ ] 실제 도입 여부
- [ ] 등장 횟수
- [ ] 첫 등장 위치
- [ ] 자연스러운 유도 방법
- [ ] 카메라 이동
- [ ] 점프 높이 최종값

## I. 플레이테스트 조정
현재 시작값:
- 레인 이동 0.2초
- 점프 0.8초
- 점프 쿨타임 1.2초
- 보스 예고 0.8초
- 전체공격 예고 1.0초
- 공격 0.6초
- 휴식 0.6초

테스트:
- [ ] 레인 이동 감각
- [ ] 점프 감각
- [ ] 쿨타임 적절성
- [ ] 보스 예고 반응시간
- [ ] 1보스 < 2보스 < 3보스 체감
- [ ] 일반 구간 난이도와 지루함 여부

## 현재 판단
핵심 구조는 이미 구현 가능한 수준.

다음 우선순위:
