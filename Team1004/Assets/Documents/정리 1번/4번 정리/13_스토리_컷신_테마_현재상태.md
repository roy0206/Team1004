# 스토리 / 컷신 / 테마 — 현재 상태

## 현재 확정된 방향
스토리는 단순히:
> 연어니까 본능적으로 고향으로 돌아간다.

로 끝내지 않는다.

**초지일관이 감정적으로 숨어 있는 이야기**를 만든다.

## 요구사항
- 연어가 돌아가야 하는 이유가 의미 있어야 함
- 처음 품은 뜻이 마지막까지 이어져야 함
- 엔딩에서 처음의 의미가 회수되면 좋음
- 중간 컷신은 각각 5문장 이하를 유지하는 방향
- 컷신이 길어서 플레이 흐름을 깨면 안 됨

## 컷신 위치 — 확정
1. 시작 스토리
2. 컷신 1 — 낚싯줄 직전
3. 컷신 2 — 바다코끼리 직전
4. 컷신 3 — 폭포 직전
5. 엔딩

## 최근 논의한 후보 — 미확정
### 약속의 연어
어린 시절 한 인간 아이와 어린 연어 사이에:
> 언젠가 여기서 다시 만나자.

라는 약속이 생기고, 몇 년 뒤 둘이 각자의 삶을 거친 뒤 다시 돌아오는 방향.

장점:
- 생태 본능보다 감정적 의미가 강함
- 약속을 끝까지 지키는 초지일관 표현
- 엔딩에서 약속 회수 가능

## 아직 확정하지 않은 것
- 인간 아이 실제 등장 여부
- 인간과 연어의 관계
- 정확한 대사
- 엔딩 톤
- 감동/비극/따뜻함의 정도
