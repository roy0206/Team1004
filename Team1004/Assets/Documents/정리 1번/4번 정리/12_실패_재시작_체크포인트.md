# 실패 / 재시작 / 체크포인트

## 체력 — 확정
체력 시스템 없음.

> 한 번 충돌 = 실패

## 일반 구간 실패 — 확정
해당 일반 구간 처음부터.

예:
진행 2에서 충돌 → 진행 2 처음.

## 보스 실패 — 확정
해당 보스의 30초 시작 지점부터.

예:
바다코끼리에서 충돌 → 바다코끼리 처음.

## 컷신 재생 — 확정
직전 컷신을 이미 봤다면 보스 재도전 시 자동 생략.

## 실패 화면
최소 구성 권장:
- 실패
- 다시하기
- `R - 다시하기`

## 일시정지
필수 확정은 아님.

필요 시:
- ESC
- 계속하기
- 처음으로

설정 메뉴까지 확장하지 않는다.
