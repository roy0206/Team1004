# 초지일관 연어 게임 — 분할 기획서 전체 목차

현재까지 확정된 게임 기획을 영역별 Markdown 파일로 분리한 최신본이다.

## 사용 원칙
- **확정** 항목은 현재 구현 기준으로 사용한다.
- **미확정 / 검토 중** 항목은 Claude가 임의로 구현하지 않는다.
- 최근 논의한 **상류 단차 점프**는 아직 확정 전이므로 별도 미확정 문서에만 기록한다.
- 새 기능 추가보다 **처음부터 엔딩까지 완주 가능한 프로토타입 완성**을 우선한다.

## 핵심 확정사항 요약
- 2D 사이드뷰 연어 게임
- 물속 3개 레인
- 연어는 오른쪽으로 전진하는 느낌
- 배경과 기본 물 흐름 표현은 왼쪽
- 평소 물 흐름은 게임 내내 동일
- 3보스 공격 순간에만 해당 레인에 강한 물줄기 발생
- 일반 장애물: 돌 / 다른 물고기 / 통나무
- 보스 3개 모두 30초 버티기
- 모든 보스 공격 전 위험 레인 히트박스 표시
- 보스 난이도: 낚싯줄 < 바다코끼리 < 폭포
- 최종 보스 이후에도 마지막 일반 구간이 존재하고, 실제 목적지 도착 후 엔딩
