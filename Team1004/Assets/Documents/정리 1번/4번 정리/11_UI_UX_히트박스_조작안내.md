# UI / UX / 히트박스 / 조작 안내

## 점프 쿨타임 UI — 확정
위치:
> 화면 좌측 하단

형태:
- 원형 게이지
- 점프 가능 시 가득 참
- 점프 사용 시 비움
- 1.2초 동안 시계 방향으로 충전
- 숫자 카운트다운 없음

## 보스 타이머 — 확정
위치:
> 화면 상단 중앙

예:
**낚싯줄**
`30`

30 → 29 → 28...

- 보스 HP바 없음

## 공격 히트박스 — 확정
- 반투명 빨간 직사각형
- 약 30~40% 투명도 권장
- 위험 레인을 명확하게 덮음
- 실제 공격 판정과 정확히 일치

## 진행도 UI — 선택
예:
**고향까지**
`━━━━●━━━━━━`

제작 시간이 부족하면 제거 가능.

## 조작 안내 — 아직 최종 확정 전
추천:
- `↑ ↓ : 이동`
- `가장 위에서 ↑ : 점프`

게임 진행 1 초반에 2~3초 표시 후 사라짐.

별도 튜토리얼 스테이지는 만들지 않는 방향 권장.

## 상류 단차 관련 안내
아직 미확정이므로 본 UI에 구현하지 않는다.
