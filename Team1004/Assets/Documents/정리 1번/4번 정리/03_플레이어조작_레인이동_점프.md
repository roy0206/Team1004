# 플레이어 조작 / 레인 이동 / 점프

## 3레인 구조 — 확정
1. 1번 레인 = 위
2. 2번 레인 = 중간
3. 3번 레인 = 아래

시작 위치: **2번 레인**

## 가로 조작
없음.

플레이어는 화면 왼쪽 부근에 있고, 배경과 장애물이 왼쪽으로 이동하여 오른쪽으로 전진하는 느낌을 만든다.

## 위/아래 이동
- `↑` 또는 `W`: 한 레인 위
- `↓` 또는 `S`: 한 레인 아래
- 키를 누르고 있어도 여러 레인 연속 이동하지 않음

## 레인 이동 시간 — 확정
약 **0.2초**

## 이동 중 규칙
- 레인 이동 중 장애물 충돌 판정 없음
- 이동 중 추가 ↑ / ↓ 입력 무시
- 입력 버퍼 없음
- 이동 완료 순간 충돌 판정 재개

## 경계 입력
- 3번 레인 + ↓ → 아무 일도 없음
- 1번 레인 + ↑ → 점프 가능한 경우 점프

## 점프 — 확정
1번 레인에서 `↑` 또는 `W`.

- 별도 Space 점프 없음
- 점프 지속 약 **0.8초**
- 점프 중 수중 장애물 충돌 무시
- 점프 중 ↑ / ↓ 무시
- 점프 후 1번 레인 착지

## 점프 쿨타임 — 확정
착지 후 **1.2초**

쿨타임 중 1번 레인에서 ↑를 눌러도 점프하지 않는다.

## 점프 높이
연어가 물 밖으로 충분히 솟는 점프를 사용한다.
