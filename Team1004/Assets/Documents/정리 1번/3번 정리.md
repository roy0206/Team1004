# 초지일관 연어 게임 통합 기획서
## Claude 프로토타입 제작용 / 최신 업데이트본

> **문서 목적**  
> 이 문서는 현재까지 확정된 게임 기획을 한 번에 정리한 최신본이다.  
> Claude는 이 문서를 기준으로 추가 질문 없이 플레이 가능한 프로토타입을 우선 제작한다.  
> 아직 확정되지 않은 스토리 대사는 임의로 길게 추가하지 말고, 임시 문구 또는 데이터 구조만 준비한다.

---

# 1. 게임 개요

## 핵심 주제
**초지일관(初志一貫)**

이 게임에서 초지일관은 단순히 같은 행동을 반복하거나 한 방향으로만 가는 것이 아니다.

> **상황과 방법은 달라져도, 처음 품었던 뜻은 끝까지 바꾸지 않는 것.**

주인공 연어가 처음 정한 목표는:

> **“내가 태어난 곳까지 돌아간다.”**

플레이 중 여러 장애물과 보스를 만나더라도 목적지는 바뀌지 않는다.

최종 보스를 쓰러뜨리는 것이 게임의 진짜 목표가 아니라,  
**보스들을 모두 지나 실제 고향까지 도착해야 게임이 끝난다.**

---

# 2. 게임 장르 / 화면 구성

- 2D 사이드뷰
- 짧은 스토리형 액션 회피 게임
- 플레이어 캐릭터: 연어
- 플레이어는 화면 왼쪽에 위치
- 연어가 오른쪽으로 계속 전진하는 느낌
- 배경 및 장애물은 왼쪽으로 이동하여 전진감을 표현
- 가로 방향 조작은 없음

---

# 3. 물 표현 — 중요

이 게임은 **서핑 게임이 아니다.**

평상시 물의 흐름은 처음부터 끝까지 기본적으로 동일하다.

- 기본 물 흐름 표현은 항상 **왼쪽 방향**
- 일반 구간이 어려워진다고 해서 물결이나 파도가 강해지지 않음
- 구간에 따라 파도 크기나 물살 세기가 변화하지 않음
- 일반 플레이에서 물 자체는 난이도 요소가 아님

## 유일한 예외: 3보스 폭포전

3보스의 공격이 발생할 때만:

1. 공격할 레인에 히트박스 예고
2. 해당 레인으로 순간적으로 **강한 물줄기 + 돌**
3. 공격 종료
4. 다시 기존의 평범한 물 흐름 표현으로 복귀

즉, **3보스 공격 순간 외에는 물 표현 자체가 변화하지 않는다.**

---

# 4. 플레이 레인

물속에는 총 3개의 레인이 있다.

1. **1번 레인 = 위**
2. **2번 레인 = 중간**
3. **3번 레인 = 아래**

게임 시작 위치:

> **2번 레인(중간)**

---

# 5. 기본 조작

## 위 이동
- `↑` 또는 `W`
- 한 번 누르면 한 레인 위로 이동
- 누르고 있어도 여러 칸 연속 이동하지 않음

## 아래 이동
- `↓` 또는 `S`
- 한 번 누르면 한 레인 아래로 이동

## 점프
플레이어가 이미 **1번 레인(위)**에 있을 때 `↑` 또는 `W`를 다시 누르면 점프한다.

- 별도의 Space 점프 없음
- 물 밖으로 뛰어오르는 연어 특유의 점프
- 점프 후 다시 1번 레인으로 착지

---

# 6. 레인 이동 상세 규칙

- 레인 이동 시간: 약 **0.2초**
- 즉시 위치 변경이 아니라 부드럽게 이동
- 레인 이동 중에는 장애물 충돌 판정을 하지 않음
- 이동 중 추가 ↑ / ↓ 입력 무시
- 입력 버퍼 없음
- 이동이 완료된 순간부터 충돌 판정 재개

## 경계 입력
- 3번 레인에서 `↓` → 아무 일도 없음
- 1번 레인에서 `↑` → 점프 가능 상태라면 점프

## 동시 입력
- ↑와 ↓가 거의 동시에 들어오면 먼저 들어온 입력 적용
- 완전히 동시에 들어오면 둘 다 무시

---

# 7. 점프 상세 규칙

- 점프 지속시간: 약 **0.8초**
- 점프 중 수중 장애물 충돌 무시
- 점프 중 ↑ / ↓ 입력 무시
- 점프가 끝나면 1번 레인에 착지
- 착지 순간부터 충돌 판정 재개

## 점프 쿨타임
- 착지 후 **1.2초**
- 쿨타임 중 1번 레인에서 ↑를 눌러도 점프하지 않음

점프를 계속 반복하여 모든 장애물을 무시하는 플레이를 막기 위한 시스템이다.

# 9. 일반 게임 구간 시간 — 확정

| 구간 | 시간 | 역할 |
|---|---:|---|
| 게임 진행 1 | **25초** | 조작 적응 / 쉬운 구간 |
| 게임 진행 2 | **30초** | 중간 난이도 |
| 게임 진행 3 | **35초** | 가장 어려운 일반 구간 |
| 게임 진행 4 | **15초** | 고향 도착 전 엔딩용 구간 |

보스전은 각각 30초이므로:

- 일반 플레이 총합: 105초
- 보스 플레이 총합: 90초
- 순수 플레이 약 3분 15초
- 컷신 포함 약 4분 전후를 목표

게임 진행 4는 어려운 구간이 아니라  
**고향에 거의 도착했다는 감정을 전달하는 짧고 비교적 평온한 구간**으로 사용한다.

# 10. 일반 장애물 — 확정

일반 구간의 장애물은 현재 아래 3종만 사용한다.

## 10.1 돌
- 가장 기본적인 장애물
- 1개 레인 차지
- 모든 일반 구간에서 사용 가능
- 화면 오른쪽에서 왼쪽으로 이동

## 10.2 다른 물고기
- 강에서 마주치는 다른 물고기
- 1개 레인 기반 장애물
- 연어 진행 방향의 반대 방향으로 지나가는 느낌
- 정확한 어종을 강조하지 않아도 됨
- 상어/고래 대신 강 분위기에 어울리는 일반 물고기 사용

## 10.3 통나무
- 떠내려오는 나무 / 통나무
- 1개 레인을 차지
- 돌보다 길이가 길어 해당 레인을 더 오래 막는 역할
- 돌과 플레이 감각을 구분

## 현재 추가하지 않는 것
- 상어
- 고래
- 수초
- 어망
- 코인
- 아이템
- 공격 시스템
- 스킬
- 업그레이드
- 상점

추가 장애물은 프로토타입이 완성된 후 시간이 남을 때만 고려한다.

# 11. 일반 구간 난이도 방향

## 게임 진행 1
- 가장 쉬움
- 장애물 등장 간격 넓음
- 단순 1레인 회피 중심
- 플레이어가 3레인 이동과 점프에 익숙해지는 구간

## 게임 진행 2
- 장애물 등장 간격 조금 감소
- 다른 물고기 / 통나무 비중 증가
- 레인을 연속으로 바꾸는 상황이 조금 더 많아짐

## 게임 진행 3
- 가장 어려운 일반 구간
- 장애물 등장 간격 추가 감소
- 연속 회피 상황 증가
- 점프를 활용하는 상황 증가

## 게임 진행 4
- 난이도 하락
- 장애물 매우 적음
- 후반에는 거의 등장하지 않아도 됨
- 고향 풍경과 도착 감정에 집중

중요:

> 난이도 상승은 장애물 속도·간격·배치로 만든다.  
> **물이나 파도가 강해지는 방식으로 난이도를 만들지 않는다.**

---

# 12. 보스전 공통 시스템 — 확정

모든 보스는 동일한 기본 구조를 사용한다.

## 공통 클리어 조건
> **30초 동안 살아남으면 클리어**

- 보스 HP 없음
- 플레이어 공격 없음
- 기존 ↑ / ↓ / 점프만 사용
- 공격에 한 번 맞으면 실패
- 30초 타이머가 0이 되면 보스전 종료

## 모든 공격의 공통 순서

1. 위험 레인에 히트박스 표시
2. 예고 시간이 지난 후 실제 공격
3. 공격이 화면을 지나감
4. 짧은 휴식
5. 다음 공격 히트박스 표시
6. 30초 동안 반복

---

# 13. 보스 공격 타이밍 — 확정

우선 모든 보스에 같은 기본값을 적용하여 제작한다.

## 일반 공격
- 히트박스 예고: **0.8초**
- 실제 공격 시간: 약 **0.6초**
- 공격 종료 후 휴식: 약 **0.6초**

기본 공격 사이클:

> 0.8초 예고 → 0.6초 공격 → 0.6초 휴식

약 2초 단위.

보스 30초 동안 대략 12~14회 정도의 공격이 나오는 것을 목표로 한다.

## 3개 레인 전체 공격
플레이어가 1번 레인까지 이동한 뒤 점프해야 하므로 조금 더 긴 예고시간을 준다.

- 전체 레인 공격 예고: **1.0~1.1초 권장**
- 기본값: **1.0초**

프로토타입 테스트 후 필요하면 보스 3만 조금 빠르게 조정할 수 있으나,  
처음 구현에서는 가급적 같은 수치를 사용한다.

# 14. 보스 1 — 낚싯줄

## 핵심
> **위험한 한 줄을 피한다.**

## 시간
- 30초 버티기

## 공격 전
- 공격할 레인에 빨간 히트박스 예고

## 공격 방식
낚싯줄 하나가 3개 레인 중 정확히 하나에 내려온다.

총 3가지 패턴:

1. **1번 레인 낚싯줄**
2. **2번 레인 낚싯줄**
3. **3번 레인 낚싯줄**

예:

- 2번 레인 히트박스 표시
- 예고 종료
- 2번 레인으로 낚싯줄 내려옴
- 플레이어가 1번 또는 3번 레인에 있으면 회피 성공
- 낚싯줄이 지나감
- 다음 공격 시작

## 특징
- 한 번에 하나의 레인만 위험
- 가장 쉬운 보스
- 플레이어가 보스전의 히트박스 예고 시스템을 배우는 역할

---

# 15. 보스 2 — 바다코끼리

## 핵심
> 낚싯줄보다 공격 범위가 넓어지고, 피해야 할 레인 판단이 어려워진다.

## 시간
- 30초 버티기

## 총 공격 패턴
**5가지**

### 패턴 1 — 1번 레인
- 1번 레인에 히트박스
- 바다코끼리가 **입을 벌리고 1번 레인으로 돌진**

### 패턴 2 — 2번 레인
- 2번 레인에 히트박스
- 바다코끼리가 **입을 벌리고 2번 레인으로 돌진**

### 패턴 3 — 3번 레인
- 3번 레인에 히트박스
- 바다코끼리가 **입을 벌리고 3번 레인으로 돌진**

### 패턴 4 — 1+2번 레인
- 1번과 2번 레인에 히트박스
- 바다코끼리가 **입과 팔을 벌리고 두 레인을 차지하며 돌진**
- 플레이어는 3번 레인으로 피해야 함

### 패턴 5 — 2+3번 레인
- 2번과 3번 레인에 히트박스
- 바다코끼리가 **입과 팔을 벌리고 두 레인을 차지하며 돌진**
- 플레이어는 1번 레인으로 피해야 함

## 존재하지 않는 패턴
- 1+3번 레인 공격 없음
- 1+2+3 전체 공격 없음
- 별도 엄니 공격 없음
- 원거리 공격 없음

## 공격 연출 구분
- **1레인 공격 = 입 벌리고 돌진**
- **2레인 공격 = 입 + 팔 벌리고 돌진**

---

# 16. 보스 3 — 폭포

## 핵심
> **강한 물줄기와 돌을 연속으로 피하고, 마지막에 폭포를 점프로 넘는다.**

## 시간
- 30초 버티기

## 총 공격 패턴
**6가지**

1. 1번 레인
2. 2번 레인
3. 3번 레인
4. 1+2번 레인
5. 2+3번 레인
6. 1+2+3번 전체 레인

## 공격 방식

1. 해당 레인에 빨간 히트박스가 먼저 표시
2. 예고 종료
3. 해당 레인에만 **강한 물줄기 + 기존 돌 장애물**이 빠르게 지나감
4. 공격이 지나간 뒤 다시 평범한 물 흐름으로 복귀
5. 다음 공격

### 1레인 공격
- 나머지 2개 레인 중 하나로 회피 가능

### 2레인 공격
- 남은 1개 레인으로 이동하여 회피

### 3레인 전체 공격
- 물속 3개 레인이 모두 위험
- 플레이어는 1번 레인으로 이동 후 점프하여 회피
- 다른 패턴보다 긴 약 1.0초 예고 사용

## 점프 쿨타임 안전 규칙
- 1+2+3 전체 공격은 플레이어의 점프가 쿨타임 중일 때 생성하지 않음
- 회피 불가능한 패턴은 절대 생성하지 않음

## 30초 종료 후
30초가 끝나면 공격 패턴 생성 중지.

이후 거대한 마지막 폭포 등장.

플레이어에게 1번 레인으로 이동할 시간을 주고:

> **1번 레인 → ↑ → 마지막 큰 점프**

폭포를 돌파하면 보스 클리어.

마지막 점프가 쿨타임에 막히지 않도록  
30초 종료 시점에는 점프를 사용 가능한 상태로 보정한다.

## 2보스
바다코끼리

- 총 5패턴
- 1레인 공격 + 2레인 공격
- 일부 공격에서는 안전한 레인이 하나뿐

↓

## 3보스
폭포

- 총 6패턴
- 1레인 + 2레인 + 3레인 전체
- 강한 물줄기 + 돌
- 전체 레인 공격은 점프 강제
- 마지막 폭포 점프까지 존재

즉:

> **3패턴 → 5패턴 → 6패턴**

으로 자연스럽게 난이도가 상승한다.

# 18. 사망 / 재시작 규칙 — 확정

## 일반 구간에서 사망
해당 일반 구간 처음부터 다시 시작.

예:

게임 진행 2에서 충돌  
→ 게임 진행 2 처음으로 복귀

## 보스에서 사망
해당 보스전 처음부터 다시 시작.

예:

바다코끼리에게 맞음  
→ 바다코끼리 30초 처음부터 재시작

## 컷신 재생
이미 한 번 본 직전 컷신은 보스 재도전 시 다시 보여주지 않는다.

## 실패 화면
최소한으로 구성.

예:

> **실패**  
> `다시하기`

키보드 기반이라면 `R - 다시하기`도 가능.

## 체력
- HP 없음
- 목숨 수 없음
- 한 번 충돌 = 실패

# 19. UI — 확정

UI는 최대한 단순하게 한다.

## 19.1 점프 쿨타임 UI
위치:

> **화면 좌측 하단**

형태:

- 원형 게이지
- 점프 가능 시 원이 가득 참
- 점프 사용 시 비어 있음
- 1.2초 동안 시계 방향으로 차오름
- 숫자 카운트다운은 없음

---

## 19.2 보스 타이머

위치:

> **화면 상단 중앙**

표시 예:

> 낚싯줄  
> **30**

시간이:

30 → 29 → 28 → ...

형태로 감소.

다른 보스도 동일한 UI 구조 사용.

- 보스 HP바 없음

---

## 19.3 진행도 UI

일반 구간에서는 작은 진행 바를 사용할 수 있다.

예:

> 고향까지  
> `━━━━●━━━━━━`

단, 이 UI는 제작 시간이 부족하면 생략 가능하다.

**필수 UI가 아니다.**

---

## 19.4 공격 히트박스 UI

모든 보스 공격에서 동일한 디자인을 사용.

추천:

- 반투명 빨간 직사각형
- 약 30~40% 투명도
- 해당 레인을 명확하게 덮음
- 실제 공격 직전 약 0.2초 정도 한 번 더 밝아져도 됨
- 과도한 파티클이나 복잡한 효과 사용하지 않음

핵심:

> 플레이어가 공격 전에 “어느 레인이 위험한지” 즉시 이해할 수 있어야 한다.

# 20. 스토리 / 컷신 — 현재 상태

스토리의 큰 방향은 확정되어 있으나  
**정확한 문장은 다음 기획 단계에서 자세히 확정한다.**

Claude 프로토타입 제작 단계에서는 실제 최종 대사를 임의로 길게 작성하지 않는다.

## 필요한 스토리 구간

1. 시작 스토리
2. 컷신 1 — 낚싯줄 직전
3. 컷신 2 — 바다코끼리 직전
4. 컷신 3 — 폭포 직전
5. 엔딩

## 컷신 길이 원칙
- 중간 컷신 1 / 2 / 3은 각각 **5문장 이하**
- 시작 스토리와 엔딩도 짧게
- 대화보다 게임 흐름을 우선
- 주인공 연어는 겁도 많고 투덜거리지만 처음 정한 목표는 포기하지 않는 성격

대표적인 주제 문장:

> **“그래도 가야지.”**

단, 실제 사용 위치와 반복 횟수는 다음 스토리 기획에서 확정한다.

---

# 21. 엔딩의 핵심 의미

3보스 폭포를 넘었다고 바로 게임이 끝나지 않는다.

반드시:

> 보스 3 클리어 → 게임 진행 4 → 실제 고향 도착 → 엔딩

순서로 진행한다.

이유:

주인공이 처음 정한 목표는:

> “보스를 모두 이긴다.”

가 아니라:

> **“내가 태어난 곳까지 돌아간다.”**

이기 때문이다.

따라서 최종 보스 이후에도 원래 목적지까지 가야  
**초지일관이라는 주제가 완성된다.**

# 22. 그래픽 방향

- 간단하고 단순한 그래픽
- 복잡한 배경 금지
- 해커톤 내 완성 가능성 우선
- 게임 플레이와 위험 레인이 한눈에 보여야 함
- 물속 배경은 1~2개 기본형을 반복 활용 가능
- 캐릭터 및 장애물은 실루엣만으로도 구분 가능해야 함

## 플레이어 연어
최소 필요 상태:

- 기본 수영
- 점프
- 충돌
- 컷신용 기본 표정
- 필요 시 겁먹음 / 지침 표정

많은 애니메이션은 필수 아님.

# 25. 구현 시 반드시 지킬 사항

1. 3개 레인 구조를 바꾸지 않는다.
2. 가로 플레이어 조작을 추가하지 않는다.
3. 별도 공격 버튼을 만들지 않는다.
4. 보스 HP 시스템을 만들지 않는다.
5. 모든 보스는 30초 버티기다.
6. 모든 보스 공격 전에 히트박스가 먼저 표시된다.
7. 낚싯줄 보스는 1 / 2 / 3 총 3패턴이다.
8. 바다코끼리는 1 / 2 / 3 / 12 / 23 총 5패턴이다.
9. 폭포는 1 / 2 / 3 / 12 / 23 / 123 총 6패턴이다.
10. 바다코끼리 1레인 공격은 입 벌리고 돌진이다.
11. 바다코끼리 2레인 공격은 입 + 팔 벌리고 돌진이다.
12. 일반 물 흐름은 항상 동일하다.
13. 물의 세기나 파도 변화로 난이도를 만들지 않는다.
14. 3보스 공격 순간에만 해당 레인에 강한 물줄기가 발생한다.
15. 일반 장애물은 우선 돌 / 다른 물고기 / 통나무만 사용한다.
16. 충돌 한 번이면 실패다.
17. 사망하면 현재 구간 또는 현재 보스부터 재시작한다.
18. 보스 재도전 시 이미 본 직전 컷신은 생략한다.
19. 3보스 이후 게임 진행 4가 반드시 존재한다.
20. 실제 고향에 도착해야 엔딩이 나온다.

# 28. 최종 핵심 요약

이 게임은 연어가 태어난 곳으로 돌아가기 위해 강을 거슬러 올라가는 짧은 2D 사이드뷰 게임이다.

플레이어는 3개 레인 사이를 위아래로 이동하고, 최상단 레인에서 점프할 수 있다.

일반 장애물은:

> 돌 / 다른 물고기 / 통나무

세 보스는 모두 30초 동안 공격을 피하는 방식이며, 모든 공격 전에 위험 레인이 빨간 히트박스로 표시된다.

### 보스 1
**낚싯줄**
- 1 / 2 / 3
- 3패턴

### 보스 2
**바다코끼리**
- 1 / 2 / 3 = 입 벌리고 돌진
- 12 / 23 = 입 + 팔 벌리고 돌진
- 5패턴

### 보스 3
**폭포**
- 1 / 2 / 3 / 12 / 23 / 123
- 6패턴
- 공격 순간에만 강한 물줄기 + 돌
- 마지막 폭포 점프

보스 난이도는:

> **1보스 < 2보스 < 3보스**

순서로 상승한다.

평소 물은 항상 동일하게 왼쪽으로 흐르는 표현만 사용한다.

게임의 핵심 메시지는:

> **상황과 방법은 달라져도, 처음 품었던 뜻은 끝까지 바꾸지 않는다.**

최종 보스를 넘은 뒤에도 게임은 끝나지 않는다.

연어가 처음부터 목표로 삼았던  
**자신이 태어난 곳에 실제로 도착했을 때 게임이 끝난다.**
