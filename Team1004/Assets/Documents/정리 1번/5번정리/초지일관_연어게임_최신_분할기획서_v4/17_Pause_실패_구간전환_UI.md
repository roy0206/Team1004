# Pause / 실패 / 구간 전환 UI

## [확정] Pause

게임 플레이 중:

> ESC

Pause 상태가 되면:

- 일반 구간 타이머 정지
- 보스 타이머 정지
- 장애물 정지
- 보스 공격 정지
- 게임 진행 정지

## Pause 메뉴

중앙 흰색 패널.

제목:

> MENU

항목:

- 계속하기
- 다시하기
- 설정
- 메인

↑/↓ 이동, Enter 선택.

ESC 재입력 시 계속하기.

## 다시하기

일반 플레이:

> 해당 일반 구간 처음

보스:

> 해당 보스 처음

## 메인

확인:

> 메인 화면으로 돌아가시겠습니까?

확인 후 TITLE.

## 실패 화면

중앙 패널:

> 실패

메뉴:

- 다시하기
- 메인

기본 포커스:

> 다시하기

단축키:

> R = 즉시 다시하기

## 보스 시작

컷신 이후 짧게:

- BOSS 1 — 낚싯줄
- BOSS 2 — 바다코끼리
- BOSS 3 — 폭포

약 1초 정도 보여준 뒤 보스 시작.

## 보스 클리어

> CLEAR

약 1초 표시 후 다음 일반 구간으로 이동.
