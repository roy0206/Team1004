# 플레이어 / 3레인 이동

## [확정] 플레이 레인

물속에는 총 3개의 레인이 있다.

1. 1번 레인 = 위
2. 2번 레인 = 중간
3. 3번 레인 = 아래

시작 위치:

> **2번 레인**

## [확정] 가로 조작

플레이어가 직접 좌우로 이동하지 않는다.

연어는 화면 왼쪽 약 20~25% 지점에 유지되고, 배경과 장애물이 왼쪽으로 지나가면서 연어가 오른쪽으로 진행하는 느낌을 만든다.

## [확정] 이동 입력

- `↑` 또는 `W`: 한 레인 위로 이동
- `↓` 또는 `S`: 한 레인 아래로 이동

한 번 입력 = 한 레인 이동.

키를 누르고 있어도 여러 칸이 자동으로 이동하지 않는다.

## [확정] 레인 이동 시간

> **0.2초**

순간이동이 아니라 부드럽게 이동한다.

## [확정] 이동 중 처리

레인 이동 중:

- 장애물 충돌 판정 없음
- 추가 ↑ / ↓ 입력 무시
- 입력 버퍼 없음

이동이 완료되는 순간부터 충돌 판정을 다시 활성화한다.

## [확정] 경계 입력

- 3번 레인에서 ↓ → 아무 일도 없음
- 1번 레인에서 ↑ → 점프 가능한 경우 점프

## 동시 입력

↑와 ↓가 거의 동시에 들어오면 먼저 들어온 입력을 사용한다.

완전히 동시에 들어온 것으로 처리되는 경우 둘 다 무시해도 된다.
