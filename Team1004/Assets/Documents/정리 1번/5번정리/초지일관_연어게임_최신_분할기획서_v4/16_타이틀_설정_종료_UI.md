# 타이틀 / 설정 / 종료 UI

첨부했던 UI 레퍼런스의 디자인 언어를 참고한다.

## [프로토타입] 타이틀

현재 제목:

> **연어의 약속**

작게:

> **初志一貫**

메뉴:

- PLAY
- SETTINGS
- QUIT

## 디자인 방향

- 밝은 회백/연보라 계열 전체 배경
- 파랑/남색 계열 패널
- 둥근 캡슐 버튼
- 선택 항목은 밝은 흰색
- 비선택 항목은 연한 회색
- 주황/코랄 포인트
- 굵고 깔끔한 산세리프

선택된 메뉴 양옆:

> `◀   ▶`

형태의 포커스 표시.

## 입력

- ↑ / ↓: 포커스 이동
- Enter: 선택
- 마우스 클릭 지원

## SETTINGS

중앙 흰색 둥근 패널.

항목:

- MASTER
- BGM
- SFX

각각:

- 0~100 슬라이더
- 오른쪽 현재 값 표시

예:

- MASTER 80
- BGM 65
- SFX 50

닫기 X 버튼.

## QUIT

확인 팝업:

> 게임을 종료하시겠습니까?

버튼:

- 종료
- 취소

기본 선택:

> 취소

브라우저에서 탭 강제 종료가 불가능한 경우:

“게임을 종료했습니다. 브라우저 탭을 닫아주세요.”

상태로 처리 가능.
