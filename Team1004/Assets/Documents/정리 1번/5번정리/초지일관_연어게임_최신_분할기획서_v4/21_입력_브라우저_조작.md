# 입력 / 브라우저 조작

## 게임플레이 입력

- W / ↑ : 위 이동 또는 1번 레인에서 점프
- S / ↓ : 아래 이동
- ESC : Pause
- R : 실패 화면에서 다시하기

Space 점프 없음.

## 메뉴

- ↑ / ↓ : 선택 이동
- Enter : 선택
- ESC : 취소/뒤로가기 또는 Pause 해제
- 마우스 클릭 지원

## 컷신

- Enter
- 마우스 클릭

으로 다음 문장.

## 브라우저

게임 영역은:

> **16:9**

비율을 유지.

브라우저 창 크기에 따라 비율을 유지하며 축소/확대.

UI는 게임 영역 기준으로 배치.

## 입력 중복 주의

게임 상태에 따라 입력을 분리한다.

예:

TITLE에서 W를 눌렀다고 플레이어가 이동해서는 안 됨.

Pause 중 게임 플레이 입력은 무시.

컷신 중 레인 이동/점프 입력 무시.
