# 초지일관 연어 게임 — 최신 분할 기획서 v4

이 폴더는 현재까지 대화에서 정리된 게임 기획을 **기능/영역별로 완전히 분리한 최신본**이다.

## 문서 상태 구분

각 문서에서 다음 상태를 구분한다.

- **[확정]**: 현재 구현 기준으로 사용
- **[프로토타입 값]**: 테스트를 위해 우선 적용하되 플레이테스트 후 변경 가능
- **[미확정]**: 아직 최종 결정하지 않은 내용
- **[후순위]**: 시간이 남을 때만 추가

## 현재 게임의 핵심

- 2D 사이드뷰 연어 게임
- 3레인 이동
- 연어가 오른쪽 방향으로 상류를 거슬러 올라가는 느낌
- 기본 물 흐름 표현은 항상 왼쪽
- 일반 플레이 중 상류 단차를 점프로 올라가는 시스템 사용
- 2단 점프 없음
- 모든 상황에서 하나의 동일한 점프만 사용
- 일반 장애물: 돌 / 다른 물고기 / 통나무
- 보스 1: 낚싯줄
- 보스 2: 바다코끼리
- 보스 3: 폭포
- 모든 보스는 30초 버티기
- 모든 보스 공격 전에 위험 레인 히트박스 표시
- 보스 난이도는 1 < 2 < 3
- 3보스가 끝나도 바로 엔딩이 아니라 마지막 일반 구간을 거쳐 목적지에 도착해야 종료
