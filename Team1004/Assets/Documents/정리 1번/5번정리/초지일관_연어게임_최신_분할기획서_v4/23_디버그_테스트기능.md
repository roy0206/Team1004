# 디버그 / 테스트 기능

웹 프로토타입을 빠르게 검증하기 위한 기능.

## DEBUG 플래그

```js
const DEBUG = true;
```

false이면 사용자 플레이에서 디버그 기능 비활성화.

## 권장 단축키

DEBUG가 true일 때:

- 1 = 게임 진행 1
- 2 = 보스 1
- 3 = 게임 진행 2
- 4 = 보스 2
- 5 = 게임 진행 3
- 6 = 보스 3
- 7 = 게임 진행 4
- 8 = 엔딩

## 테스트 시 확인할 상태 초기화

디버그 점프 시:

- 기존 장애물 제거
- 보스 공격 제거
- 타이머 초기화
- 플레이어 이동/점프 상태 초기화
- 쿨타임 상태 적절히 초기화
- Pause 상태 해제

## 목적

전체 게임을 매번 처음부터 하지 않고 각 구간을 빠르게 검증하기 위함.
