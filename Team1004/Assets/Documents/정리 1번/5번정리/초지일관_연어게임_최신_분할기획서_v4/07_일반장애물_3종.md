# 일반 장애물 3종

일반 플레이 장애물은 현재 정확히 3종만 사용한다.

## 1. 돌 — 기본형

### [확정] 역할
가장 표준적인 장애물.

- 1레인
- 기본 속도
- 기본 길이
- 가장 읽기 쉬운 장애물

## 2. 다른 물고기 — 빠른형

### [확정] 역할
반응 속도를 요구하는 장애물.

- 1레인
- 돌보다 빠름
- 상대적으로 짧게 화면을 지나감
- 정확한 어종은 중요하지 않음
- 강에서 자연스럽게 보이는 일반 물고기

## 3. 통나무 — 긴 점유형

### [확정] 역할
특정 레인을 오래 막는 장애물.

- 1레인
- 돌보다 느림
- 가로 길이가 가장 김
- 화면에 오래 남아 레인을 오래 점유

## [프로토타입] 초기 상대값

| 장애물 | 속도 배수 | 길이 배수 |
|---|---:|---:|
| 돌 | 1.0 | 1.0 |
| 물고기 | 1.25 | 0.9 |
| 통나무 | 0.8 | 1.8 |

정확한 px/s는 플레이테스트 후 수정한다.

## [확정] 현재 제외

일반 장애물로 다음은 사용하지 않는다.

- 상어
- 고래
- 어망
- 수초
- 기타 추가 생물/아이템

새 장애물은 완성 후 시간이 남을 때만 추가한다.
