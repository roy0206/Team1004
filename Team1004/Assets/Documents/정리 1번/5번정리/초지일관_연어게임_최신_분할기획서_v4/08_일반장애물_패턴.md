# 일반 장애물 패턴

## [확정] 생성 원칙

완전 무작위로 오브젝트를 던져 회피 불가능한 상황을 만들지 않는다.

> **검증된 패턴 기반 + 해당 패턴 내 장애물 종류 랜덤**

방식을 권장한다.

## 패턴 A — 단독

- `[1]`
- `[2]`
- `[3]`

한 레인에 장애물 하나.

## 패턴 B — 2레인 동시

- `[1,2]` → 3번 안전
- `[2,3]` → 1번 안전
- `[1,3]` → 2번 안전

항상 안전한 1레인이 남아야 한다.

## 패턴 C — 연속 회피

예:

- 1번 장애물 → 조금 뒤 2번
- 3번 장애물 → 조금 뒤 1번
- 2번 → 3번
- 1번 → 3번

한 번에 여러 레인을 막는 대신 연속해서 판단하도록 만든다.

## [확정] 일반 구간 전체 봉쇄 금지

일반 플레이에서는:

> `[1,2,3]`

으로 수중 3레인을 전부 막는 패턴을 사용하지 않는다.

3레인 전체 + 점프 강제는 3보스의 특징으로 남긴다.

## 장애물 종류와 패턴

패턴의 레인 구조와 장애물 종류는 분리한다.

예:

- 1번 = 돌 / 2번 = 물고기
- 1번 = 통나무 / 3번 = 돌

등 다양한 조합이 가능하지만, 항상 물리적으로 회피 가능해야 한다.
