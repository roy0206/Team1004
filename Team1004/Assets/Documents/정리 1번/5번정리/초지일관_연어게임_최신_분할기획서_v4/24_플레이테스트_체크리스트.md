# 플레이테스트 체크리스트

## 플레이어 이동

- [ ] 레인 이동 0.2초가 자연스러운가
- [ ] 이동 중 무적이 너무 강하지 않은가
- [ ] 홀드 입력이 여러 칸 이동으로 처리되지 않는가

## 점프

- [ ] 2레인 높이가 너무 과해 보이지 않는가
- [ ] 1.6초 체공이 답답하지 않은가
- [ ] 최고점/착지 느낌이 자연스러운가
- [ ] 쿨타임 1.2초가 적절한가
- [ ] 일반/단차/보스에서 같은 점프가 자연스럽게 작동하는가

## 상류 단차

- [ ] 첫 단차를 일반 플레이 중 자연스럽게 발견하는가
- [ ] 배경 `↑`를 인지하는가
- [ ] 1레인 높이가 적절한가
- [ ] 2초 접근시간이 충분한가
- [ ] 첫 단차 재시도 방식이 어색하지 않은가
- [ ] 카메라 0.7초 이동이 자연스러운가
- [ ] 두 번째 단차에서 힌트 없이 이해하는가

## 일반 장애물

- [ ] 돌 = 기본형이 느껴지는가
- [ ] 물고기 = 빠른형이 느껴지는가
- [ ] 통나무 = 긴 점유형이 느껴지는가
- [ ] 2레인 패턴이 공정한가
- [ ] 연속 패턴이 회피 가능한가
- [ ] 진행 1 < 2 < 3 난이도가 체감되는가

## 보스

- [ ] 1보스가 가장 쉬운가
- [ ] 2보스에서 1레인/2레인 공격이 구분되는가
- [ ] 3보스가 가장 어려운가
- [ ] 일반 예고 1.2초가 적당한가
- [ ] 전체공격 1.5초가 적당한가
- [ ] 빨간 영역과 실제 판정이 일치하는가
- [ ] 직전 패턴이 반복되지 않는가
- [ ] 3보스 123이 점프 쿨타임 중 나오지 않는가
- [ ] 모든 보스가 정확히 30초 종료되는가

## 실패 / 재시작

- [ ] 일반 구간 재시작이 해당 구간부터 되는가
- [ ] 보스 재시작이 보스부터 되는가
- [ ] 이미 본 컷신이 보스 재도전 때 반복되지 않는가
- [ ] 재시작 후 이전 장애물이 남지 않는가

## UI

- [ ] 게임 시작 배경 조작 안내가 보이는가
- [ ] 점프 쿨타임 UI 이해가 되는가
- [ ] Pause가 모든 진행을 멈추는가
- [ ] 키보드와 마우스 모두 메뉴 조작 가능한가

## 전체 흐름

- [ ] TITLE부터 ENDING까지 오류 없이 완주 가능한가
- [ ] 보스 3 후 바로 엔딩이 아니라 진행 4로 넘어가는가
