# 긴 바위 — 단차 / 일반 기믹

## 중요
긴 바위는 폭포 보스 대체물이 아니다.

## 공통 리소스
권장 Sprite ID: `LongRock_Tall`
- 강바닥에서 수면까지 솟은 형태
- 수중 레인 이동만으로는 통과 불가
- 1번 레인에서 점프로 넘음

## Variant A — LedgeLongRock
기존 단차 이벤트 대체.

이벤트 시점:
- SECTION1 5.0초
- SECTION1 12.5초
- SECTION2 15.0초

실패:
- GameOver 아님
- Section Timer 정지
- World Scroll 정지
- Spawn 정지
- 성공할 때까지 재시도

## Variant B — LongRock_Gimmick
일반 진행 중 등장하는 점프 장애물.
- 오른쪽→왼쪽 스크롤
- 1/2/3 수중 레인 전부 막음
- 1번 레인에서 점프 필요
- 충돌 시 일반 구간 실패

## Prefab 권장
```text
LongRockBase
├─ SpriteRenderer
└─ Collider2D

LedgeLongRock
└─ LongRockBase + LedgeChallengeController

LongRock_Gimmick
└─ LongRockBase + ObstacleMover + NormalFailCollision
```

같은 Sprite를 재사용하고 동작 Component만 분리한다.
