# 보스 패턴 공통 규칙

## 레인
- 1 = 위
- 2 = 중간
- 3 = 아래

## 공통 복합 패턴

### SEQUENTIAL_12 — 순차
`[1] → [2]`

### ROUND_TRIP_12321 — 왕복
`[1] → [2] → [3] → [2] → [1]`

### CROSS_132 — 교차
`[1] → [3] → [2]`

### PRESSURE_123 — 연속 압박
`[1] → 0.5초 → [2] → 0.5초 → [3]`
- stepInterval = 0.5초 고정

### SAFE_LANE_SHIFT_321 — 안전 레인 이동
공격: `[1,2] → [1,3] → [2,3]`
안전: `3 → 2 → 1`

## 기본 공격 레인 조합
- [1]
- [2]
- [3]
- [1,2]
- [2,3]
- [1,3]

폭포는 추가로 `[1,2,3]` 보유.

## Telegraph
- 일반 첫 Step 예고 = 1.2초
- 폭포 `[1,2,3]` = 1.5초
- 복합 패턴의 다음 Step은 이전 Step 종료 시점부터 다음 위험 레인을 표시한다.

## 공정성 규칙
1. 경고 없이 실제 Collider 활성화 금지
2. 실제 Collider가 빨간 경고 범위보다 커지면 안 됨
3. 같은 Pattern ID 즉시 반복 금지
4. 서로 다른 패턴 Collider를 겹쳐 회피 불가능하게 만들지 않음
5. Pause 중 타이머/코루틴/트윈/Collider 진행 정지
6. 보스 30초 종료 시 새 패턴 예약 금지
7. 이미 시작한 패턴은 끝낸 뒤 CLEAR
8. 페이크 패턴 없음

## 패턴 등장 보장
각 보스 30초 동안 공통 복합 5종은 각각 최소 1회 등장하도록 보장한다.
순수 Random에 맡기지 않는다.

권장 구현:
- GuaranteedPatternBag에 5종 ID 한 번씩 삽입
- Shuffle
- 보스 Phase 허용 조건에 맞춰 소비
- 전투 종료 전 미사용 패턴 우선 실행
- 기본 공격은 복합 패턴 사이에 Interleave
