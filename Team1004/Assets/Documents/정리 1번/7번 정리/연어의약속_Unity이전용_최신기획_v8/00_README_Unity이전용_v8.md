# 연어의 약속 — Unity 이전용 최신 기획 v8

## 목적
이 폴더는 Claude 웹 프로토타입용 프롬프트가 아니다.
팀원이 Google Drive에서 내려받아 Unity 프로젝트에 옮기거나, Unity 자동화/코드 생성 도구가 읽어 상태머신·패턴 데이터·프리팹·컨트롤러를 자동 제작하기 위한 구현 명세다.

## 최신 보스 구성
- BOSS 1 = 낚싯줄
- BOSS 2 = 곰
- BOSS 3 = 폭포

**폭포 보스는 폐기되지 않았다.**

## 긴 돌/긴 바위의 역할
긴 돌은 보스3 대체물이 아니다.
- 기존 단차 구간의 시각/충돌 오브젝트
- 일반 구간 점프 기믹 장애물

## 세 보스 공통 복합 패턴 5종
1. 순차 `[1] → [2]`
2. 왕복 `[1] → [2] → [3] → [2] → [1]`
3. 교차 `[1] → [3] → [2]`
4. 연속 압박 `[1] → 0.5s → [2] → 0.5s → [3]`
5. 안전 레인 이동 `[1,2] → [1,3] → [2,3]`

페이크 패턴은 사용하지 않는다.
난이도는 반드시 `낚싯줄 < 곰 < 폭포` 순서로 증가한다.
